About This Lab

This is my first Artificial Intelligence lab project. In this lab, I learned about different approaches used in AI and how they work.
To understand the concepts better, I used a scholarship screening example. I explored how a rule-based system makes decisions by following specific conditions and compared it with a probability-based approach.
I also added two new conditions to the original rule-based program and tested it with four different cases.

Files Included

Here is a quick overview of the files in this project:

- "lab1_compare.py" – This program compares the decisions made by rule-based and probability-based approaches.
- "lab1_rules.py" – This program checks scholarship applications using four conditions.
- "Lab1_Report.docx" – My lab report, including explanations, test cases, results, and conclusions.
- "outputs/" – Contains the output generated after running the Python programs.

Requirements

To run these programs, you need:

- Python 3.8 or above
- Visual Studio Code or any Python editor

No additional libraries are needed.

How to Run the Programs

First, open this project folder in VS Code. Then open the terminal and run the following commands:

For the comparison program:

python lab1_compare.py

For the rule-based program:

python lab1_rules.py

If the first command does not work, you can try "python3" instead of "python".

Conditions Used in the Rule-Based Program

The scholarship screening program checks four conditions:

1. The applicant must have a score of 70 or above.
2. All required documents must be complete.
3. The applicant must have a GPA of at least 2.5.
4. The applicant's income information must be verified.

The score and GPA thresholds are synthetic lab assumptions used only for this activity.

If all four conditions are satisfied, the program returns Review. Otherwise, it returns Hold.

What I Learned

While working on this lab, I understood how a rule-based system follows fixed conditions to make decisions. I also learned that a probability-based approach can sometimes give a different result for the same application.

The most useful part of this activity was testing different cases and checking whether the program gave the expected output. It helped me understand why testing is important when developing an AI system.

Important Note

This project is created for learning and demonstration purposes. The values and conditions are not official scholarship requirements. Also, Review does not mean that an applicant has received a scholarship. It only means that the application should be checked by a human reviewer.
